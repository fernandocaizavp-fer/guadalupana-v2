Actúa como mi desarrollador frontend de Angular. Necesito integrar el widget de nuestro chatbot de Voiceflow en la aplicación.

Ubica el archivo principal index.html (normalmente en frontend/src/index.html). Inserta el siguiente script exactamente justo antes de la etiqueta de cierre </body>:

<script type="text/javascript">
  (function(d, t) {
      var v = d.createElement(t), s = d.getElementsByTagName(t)[0];
      v.onload = function() {
        window.voiceflow.chat.load({
          verify: { projectID: '6ab894ab6920e1782997de07' },
          url: 'https://general-runtime.voiceflow.com',
          voice: {
            url: "https://runtime-api.voiceflow.com"
          }
        });
      }
      v.src = "https://cdn.voiceflow.com/widget-next/bundle.mjs"; v.type = "text/javascript"; s.parentNode.insertBefore(v, s);
  })(document, 'script');
</script>


Una vez que hayas insertado y guardado el archivo, ejecuta los comandos para subir esto a producción: git add ., luego git commit -m "feat: integrar chatbot de Voiceflow en index.html" y finalmente git push origin main.
